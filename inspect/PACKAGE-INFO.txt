AOSP 涟漪移植展示 · 打包说明
================================================
构建时间：2026-11-22 04:54（第 25 轮）
基线：AOSP Android 17 (android-17.0.0_r1) · @material/web 2.5.0（pkg/ 原文内联运行）· MDC-Android 1.14.0
· Monet CoreSpec = packages/SystemUI/monet ColorScheme.kt（aosp-mirror android-13.0.0_r1）

一、本包内容
------------------------------------------------
1) aosp-ripple-port-web-src.zip —— Next.js 预览工程源码（可复现构建）
   - src/        9 个 aosp 引擎文件 + 22 个组件文件 + 官方对照 iframe
   - public/     official-md-ripple（pkg/ 原文 + vendor/ lit 3.3.2）、字体、页脚内嵌源码包
   - evidence/   MDC-Android 1.14.0 官方 AAR + tokens 取证转储
   - 根配置      package.json / next.config.ts / tsconfig / tailwind / bun.lock / .gitignore
2) aosp-ripple-port-web-dist.zip —— GitHub Pages 静态导出产物
   NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop 生成（out/），解压即站点；
   纯静态、无 node_modules，与 gh-pages 分支同源。

二、第 25 轮变更（用户复核两弹驱动）
------------------------------------------------
- "剪切"按钮 content_cut 矢量图标路径还原为 Material Icons 原版
  （此前路径为损坏手写版：弧线端点/圆孔半径全错，渲染畸形；同组复制/粘贴本为原版）
- 7 种几何形变加载指示器画布清晰度修复：撤销 2.5 DPR 上采样顶，
  改按真实 devicePixelRatio × visualViewport 捏合缩放逐帧重设后备缓冲（封顶 8 防病态值）；
  硬边贝塞尔剪影在浏览器缩放/捏合下不再比周围 SVG/文本发虚；
  大面积软边 WebGL 涟漪画布维持 2.5 封顶（差异不可见，既定性能口径）
- 导航抽屉（standard + modal）纵向滚动锁定：滚动容器补 overflow-x hidden +
  touchAction pan-y + overscrollBehavior contain；条目按钮去掉 w-full
  （100% 宽 + marginInline 12 曾撑出 12px 横向溢出——"能左右滑"真根因）
- 底部导航/侧边导航轨/导航抽屉：激活胶囊（56×32）、hover 层与角标改锚定到
  精确 24×24 图标盒（内联 svg 基线排版上浮 + "图标+文字"整组居中曾使胶囊/角标错位）；
  侧边导航轨补角标演示（首页 99+，折叠/展开两形制同锚定）
- ThemeVariant 由 tonal_spot|expressive 扩展为 styleList 全集（+spritz/vibrant），
  buildM3Theme 调色板 CoreSpec 逐值取自 AOSP-13 ColorScheme.kt L136-186
  （Spritz 12/8/16 中性 2/2 · Vibrant MaxOut(130)/旋转表 24/32 中性 10/12，联网逐字核对）
- 配色方案圆形预览 8 颗全部可点击：点击 = 应用该风格 + 该行明暗模式
  （行 = 浅/深 preview，列 = TONAL_SPOT/SPRITZ/VIBRANT/EXPRESSIVE；
  选中外圈 = themeVariant × isDark 联合判定）；实验区变体选择器同步扩为 4 项
- 四象限圆形预览加同色 0.75 描边消除扇形共享边抗锯齿发丝缝
- 端到端：tsc 零错误 · 浏览器实测（胶囊对中/角标贴角/抽屉 scrollWidth==clientWidth/
  强制 scrollLeft=0/预览点击切风格+明暗/实验区选择器联动/形变画布 48×dpr 重设）

三、运行
------------------------------------------------
  bun install && bun run dev          # http://localhost:3000
  NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop bun run build   # 静态导出 out/
  （注：next.config.ts build 脚本尾部的 cp 步骤仅 standalone 形态需要，
   导出形态出现 cp 报错可忽略——out/ 已生成）
