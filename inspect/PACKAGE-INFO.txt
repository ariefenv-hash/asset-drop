AOSP 涟漪移植展示 · 打包说明
================================================
构建时间：2026-11-22（第 21 轮）
基线：AOSP Android 17 (android-17.0.0_r1) · material-web 2.5.0 · MDC-Android 1.14.0

一、本包内容
------------------------------------------------
1) aosp-ripple-port-web-src.zip —— Next.js 预览工程源码
   - src/             全部移植组件（22 个组件文件 + 9 个 aosp 引擎文件）
   - public/          官方对照 iframe、字体、内嵌源码包
   - evidence/        MDC-Android 1.14.0 取证转储（material.aar + 12 份 tokens.xml
                      + resolved-structural.txt 162 项引用链解析）
   - 根配置            package.json / next.config.ts / tsconfig / tailwind 等

2) aosp-ripple-port-web-dist.zip —— GitHub Pages 静态导出产物
   - out/             NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop 官方静态导出
                      （纯静态 HTML/JS/CSS + .nojekyll，解压即站点）

三、取值标注约定
------------------------------------------------
✓ = MDC-Android 1.14.0 AAR / tokens.xml 逐行核实
◇ = tokens 未覆盖该项，取 M3 规范默认或主题映射（如实标注，不冒充源码值）

四、构建复现
------------------------------------------------
bun install
bun run build                      # standalone 形态（预览容器）
NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop bunx next build   # Pages 静态导出
