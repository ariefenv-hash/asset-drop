AOSP 涟漪移植展示 · 打包说明
================================================
构建时间：2026-11-22 00:43（第 18 轮）
基线：AOSP Android 17 (android-17.0.0_r1) · material-web 2.5.0 · MDC-Android 1.14.0

一、本包内容
------------------------------------------------
1) aosp-ripple-port-web-src.zip —— Next.js 预览工程源码
   - src/             全部移植组件（20+ 组件文件 + 9 个 aosp 引擎文件）
   - public/          官方对照 iframe、字体、内嵌源码包
   - 根配置            package.json / next.config.ts / tsconfig / tailwind 等

2) aosp-ripple-port-web-dist.zip —— 生产构建产物（standalone）
   - standalone/      bun run build 产物，NODE_ENV=production bun server.js 即起

二、第 18 轮变更（对齐官方 24 类清单）
------------------------------------------------
- 修复：横向拉伸 Overscroll 右缘锚点（内容层显式 948px，四向锚点齐全，
  右缘越界 pinned 实测通过）；移动端 flex-col fit-content 溢出修复（scrollW 390）
- 补齐 12 类 M3 组件：Badges / Checkbox / Radio / Chips / Snackbar / Tabs /
  Cards / Dialogs / Divider / Menus / Tooltips / Text fields
  （全部 token 接线自 MDC-Android 1.14.0 官方 AAR + tokens.xml，通道矩阵见
  src/components/ripple/M3CoreComponentsGallery.tsx 头注释）
- 取证通道矩阵：raw.github / api.github / WebFetch / dl.google.com 官方 AAR /
  googlesource（阻断），radio+textfield token 与 checkbox 矢量几何等仅官方 AAR 提供
- 诚实缺口清单：App bars / Navigation / Sheets / Search / Carousel /
  Date & time pickers（6 类重组件暂缓，见页内表格）
- 产物标记自检：data-stretch-local / stretchScaleFor / GOOGLE_BLUE /
  M3 官方清单缺口补齐 / m3_comp_radio_button 等全部命中

三、运行
------------------------------------------------
  bun install && bun run dev   # http://localhost:3000
  bun run build && bun run start
