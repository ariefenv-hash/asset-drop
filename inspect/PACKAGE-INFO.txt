AOSP 涟漪移植展示 · 打包说明
================================================
构建时间：2026-11-22 05:12（第 26 轮）
基线：AOSP Android 17 (android-17.0.0_r1) · @material/web 2.5.0（pkg/ 原文内联运行）· MDC-Android 1.14.0

一、本包内容
------------------------------------------------
1) aosp-ripple-port-web-src.zip —— Next.js 预览工程源码（可复现构建）
   - src/        9 个 aosp 引擎文件 + 22 个组件文件 + 官方对照 iframe
   - public/     official-md-ripple（pkg/ 原文 + vendor/ lit 3.3.2）、字体、页脚内嵌源码包
   - evidence/   MDC-Android 1.14.0 官方 AAR + tokens 取证转储
   - 根配置      package.json / next.config.ts / tsconfig / tailwind / bun.lock / .gitignore
2) aosp-ripple-port-web-dist.zip —— GitHub Pages 静态导出产物
   NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop 生成（out/），解压即站点；
   纯静态、无 node_modules，与 gh-pages 分支同源。

二、第 26 轮变更（用户复核第 4 弹：全项目降采样排查 + 开关状态层偏移）
------------------------------------------------
- 全项目降采样排查收官：新增共享口径 effectiveRasterDpr(cap) =
  devicePixelRatio × visualViewport.scale（捏合缩放），封顶防病态值；
  · 小画布全部给足真实分辨率（cap 8）：开关状态层 40dp · 涟漪面 24-96dp ·
    形变指示器 48dp（第 25 轮已修，本轮收敛到同一助手）
  · 大面积 WebGL 实验区舞台 cap 2.5 → 4（软边涟漪下收益递减，限幅保帧率，
    数学叠层半径换算同步）
- 开关状态层圆形"偏下 + 松手跳一下"根修：绝对定位包含块为 padding box，
  unchecked 态 border-2 把固定 top 值整体压低 2px（实测圆心 18 vs 小球 16），
  checked 翻转瞬间跳变 2px；top 改 calc(50% - 20px) 后两种状态、翻转前后
  圆心恒与 border-box 中心重合（浏览器逐帧采样实测翻转全程 cy=16 无跳变）
- 顺带审计：RippleSurface/Switch 空闲画布停在默认 300×150 属正常
  （tick 首帧先重设后绘制，空闲透明不可见）；共享 WebGL 渲染器画布按
  调用方 dpr 逐次重设，无隐藏瓶颈
- 端到端：tsc 零错误 · unchecked/checked delta 均为 0 · 双向翻转逐帧采样无跳变 ·
  实验区触发生成无报错 · 三 zip 同源同哈希

三、运行
------------------------------------------------
  bun install && bun run dev          # http://localhost:3000
  NEXT_EXPORT=1 NEXT_BASE_PATH=/asset-drop bun run build   # 静态导出 out/
  （注：next.config.ts build 脚本尾部的 cp 步骤仅 standalone 形态需要，
   导出形态出现 cp 报错可忽略——out/ 已生成）
