B. 细节动画三件套（新增组件，全部真实源码转译，出处见各组件头注）
1) SwipeRefreshDemo —— androidx SwipeRefreshLayout（1454 行）+ CircularProgressDrawable
   逐值移植：DRAG_RATE 0.5 / 触发线 64dp / 圆径 40·56dp / 回收 200ms /
   起始透明度 76 / 减速插值器 factor 2；环动画 1332ms 单周期（弧长 0.01-0.8 前后半
   FastOutSlowIn、环自转 0.21、组旋转 216°/圈、SHRINK@0.5、COLOR_CHANGE@0.75）、
   CENTER_RADIUS 7.5/11 · STROKE 2.5/3 · ARROW 10×5/12×6 · COLORS={BLACK}；
   诚实边界：VelocityTracker 抛掷判速未移植（Web 以位移判据等价）、箭头
   arrowScale 逐帧微调未复刻（保留 0.3 显隐判据）
2) SpringLabDemo —— androidx compose `object Spring` 劲度/阻尼预设实验室
   （VectorizedAnimationSpec.kt L835-880：StiffnessHigh 10000 / Medium 1500（spring()
   默认）/ MediumLow 400（进退场默认）/ Low 200 / VeryLow 50；DampingRatioHighBouncy
   0.2 / MediumBouncy 0.5（默认）/ LowBouncy 0.75 / NoBouncy 1（默认）；
   DefaultDisplacementThreshold 0.01）；物理方程 = SpringSimulation.kt L62-68
   （accel = -k·x - c·v，c = 2·√k·ζ），复用引擎 spring.ts 精确步进；
   拖拽浮子/轻弹（初速 -1400px/s）观察回弹手感，拖尾点迹可视化过冲振荡
3) CheckboxDrawDemo —— MDC-Android 1.14.0 Checkbox 三态图标动画（AAR 离线取证）：
   勾形路径 M14,18.2…20.6,11.6z / 横线 M13.4,15…21,15z（32×32 viewport，
   values.xml string 原文）；unchecked→checked = scale 0.6→1 @350ms
   emphasizedDecelerate(0.1,0.7,0.1,1) + trimPathEnd 0→1；checked→unchecked =
   scale 1→0.6 @150ms emphasizedAccelerate(0.3,0,0.8,0.2) + fillAlpha 1→0 @50ms
   linear；半选 = pathData 勾↔横线形变 @350ms（Web 端 WAAPI d 插值）；
   时长 token short1=50/short3=150/medium3=350（AAR values.xml integer）
- 新增 evidence/round30-evidence.md：6 枚字体 fvar 逐轴档案 + androidx Spring/
