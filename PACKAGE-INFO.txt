B. 反推值修正（本轮实质变更）
1) SystemUI 涟漪时长：旧版自创 3000ms（命名 "DEFAULT_RIPPLE_EFFECT_DURATION"）
   与对照 750ms —— AOSP main 分支全仓检索均无此常量，查无源码依据。
   真实取值表：RippleView.kt L46 duration 默认 = 1750ms（充电涟漪
   WiredChargingRippleController 未改 duration 即用此值）；媒体触控涟漪
   MediaControlViewBinder.kt duration = 1500L；解锁涟漪 AuthRippleController.kt
   L433 RIPPLE_ANIMATION_DURATION = 800ms；RippleAnimationConfig.duration 默认 0
   由调用方指定。RippleEngine.ts 以 AOSP_RIPPLE_VIEW_DURATION/MEDIA_TOUCH/
   AUTH 三常量落档，InteractiveLab 时长切换改为真实三档
2) SystemUI 最大扩散尺寸：旧版自创 max(w,h)×0.725 与 ellipse 固定系数 0.68 ——
   SystemUI 全仓检索无 0.725/0.68。真实语义 = setMaxSize(maxWidth,maxHeight)
   由调用方显式传入（RippleSize.update 线性乘 progress）：圆 = 充电涟漪直径
   max(w,h)×2（WiredChargingRippleController.layoutRipple，终态半径=max(w,h)
   铺满屏幕）；媒体涟漪 = 视图宽×2；解锁涟漪 = (传感器半径×0.9)×2；
   ROUNDED_BOX/ELLIPSE main 分支无 AOSP 调用方 → 演示按视图尺寸适配并如实标注
3) shaders.ts AOSP_SESSION_JAVA_SOURCE 展示块：uniform 映射此前误挂
   RippleAnimationSession.java 名下，现拆分标注到 RippleShader.java 对应行号
4) package.json：devDependencies 补 @types/node（tsc --noEmit 全绿所需）
