还原基准声明（铁律 6，长期有效）
------------------------------------------------
本包还原基准 = **AOSP / Android 17 对应源码的 Kotlin、Java 与 XML 资源文件**
（AOSP framework / SystemUI / MDC-Android / androidx Compose material3），
**不是 Material 网页版（@material/web）的二次改造**——网页版实现有自己的取舍，
不作为还原依据、不引入实现；dist 里的 official-md-ripple/ 目录仅为页内
「官方对照」区展示用素材。取值与网页版相同时必须另找 Android 侧出处证明。
Android 侧两套官方缓动令牌（勿混淆，均系 Android 源码）：MDC-Android 1.14.0
View 体系 tokens（decelerate 0.1,0.7,0.1,1 / accelerate 0.3,0,0.8,0.2）与
androidx Compose material3 Expressive MotionTokens（0.05,0.7,0.1,1 /
0.3,0,0.8,0.15），按被移植组件的源库取值，出处见各组件注释与 WORKLOG。

------------------------------------------------

   - evidence/   MDC-Android 1.14.0 官方 AAR + tokens 取证转储 +
                 round30-evidence.md（可变字体 fvar 逐轴实测 + 动画真值档案）
   - 根配置      package.json / next.config.ts / tsconfig / postcss / eslint / bun.lock / .gitignore

  真基线做逐文件三方合并（14 个共同差异文件逐一定位归属，三处双改手工合并），
  双方工作零丢失。
- 【合并入】本侧第 29 轮工作：
  · Checkbox 官方动画（MDC-Android 1.14.0 checkbox ASLD/AVD）：unchecked→checked
    = 盒/勾 scale 0.6→1.0（350ms · emphasized-decelerate 0.1,0.7,0.1,1）+
    fillAlpha 50ms linear + 勾 trimPathEnd 0→1（AOSP hwui applyTrim 语义，rAF
    部分轮廓重建）；checked→unchecked = scale 1.0→0.6（150ms · accelerate
    0.3,0,0.8,0.2）+ 50ms 淡出；勾↔减号 = pathData 形变 350ms；初始渲染静置
  · Radio 官方动画（AppCompat animated-selector → AVD）：off→on 498ms 三段
    （点 0→0→1.5→1.0 过冲 + 环 1→0.5→0.9→1.0 + 描边 2→18→2 脉冲）；on→off
    499ms 三段反向；几何闭环 btn_radio_{on,off}_mtrl.xml；is-armed 门控
  · AospExpressiveSwitch 小球按压 Android 双向 100ms standard、位移 250ms
    AccelerateDecelerate（摘除网页版独有过冲缓动）
  · 还原基准声明落库：WORKLOG 铁律 6 + README.md + pushctx 文档 + 页尾声明栏
  · PWA 化：manifest.webmanifest（全相对 URL ./）· sw.js（scope 自解析，导航
    network-first + 静态 SWR，跨源 CDN 不接管）· PwaRegister.tsx（仅生产注册）·
    layout metadata（图标组 + appleWebApp + themeColor 亮暗双档）
  · PWA 图标：Google Sans Flex 最窄字形 wdth=25（fvar 轴最小值）「M3」黑字 +
    涟漪触点装饰（icon-512/192/32、maskable-512 安全区断言、apple-touch-180、
    favicon.ico(16/32/48)、icon.svg 同源矢量重建；scripts/r29_pwa_icons.py）
- 【承接对方】第 29/30 轮全部工作见其 MANIFEST/WORKLOG 记录（9 引擎重考据 /

三、运行
------------------------------------------------
  bun install && bun run dev          # http://localhost:3000
  NEXT_EXPORT=1 NEXT_BASE_PATH=/md3e-try bun run build   # 静态导出 out/
  （注：next.config.ts build 脚本尾部的 cp 步骤仅 standalone 形态需要，
   导出形态出现 cp 报错可忽略——out/ 已生成）
